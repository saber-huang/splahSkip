# SplashSkip

一个 Android 小工具：打开其他 App 时，**自动点击开屏广告上的“跳过”按钮**。

原理是 Android 的“无障碍服务”：在你打开某个 App 后的几秒内，查看屏幕上有没有“跳过”按钮，有就替你点一下。**没有联网权限，不上传任何内容。**

## 功能

- 只对你勾选的 App 生效（应用白名单），并且有总开关
- 规则可以自己改：按钮上的文字关键词、按钮 ID 关键词、生效的秒数、文字最长几个字
- 诊断记录：广告没跳过时，记录一次界面信息，复制给作者就能排查
- 首页显示累计跳过次数；支持浅色 / 深色模式

## 下载和安装

1. 打开本仓库的 [Releases](../../releases) 页面，下载最新的 `SplashSkip-x.y.z.apk`。
2. 安装。手机提示“未知来源”时选择允许；**华为手机需要先关闭“纯净模式”**（设置 → 安全 → 更多安全设置）。
3. 打开 SplashSkip，第一次会自动显示使用说明，之后可以从首页的“使用说明与隐私”进入。

需要 Android 7.0 及以上。

## 怎么使用

1. 首页点“去开启无障碍服务”，在系统设置里找到 SplashSkip 并打开。
2. 点“选择生效的 App”，勾选想自动跳过广告的 App。
3. 点“防止被系统关闭”，按提示设置，否则手机可能在后台把它关掉。
4. 把要跳广告的 App 从多任务界面划掉，再重新打开。

## 测试情况和已知限制

**请先看这里，别指望它对所有 App 都有效：**

- 目前只在**华为手机（HarmonyOS 4.2 / Android 12）**上，针对**网易有道词典**的开屏广告测试过。其他手机、其他 App 可能需要调整规则，小米、OPPO、vivo 等手机的后台管理更严格，可能需要额外设置。
- 只能识别按钮上的**文字、无障碍描述和元素 ID**。如果广告整个画成一张图，按钮上既没有文字也没有 ID，就识别不了。
- 每次打开 App 只点一次，并且只在设定的秒数内。

## 没跳过怎么办

1. 确认首页显示“已开启”，“启用自动跳过”是打开的，这个 App 已勾选。
2. 按钮上的字不是“跳过”：在“规则设置”里加上。**不要加“广告”“VIP”这类词**，可能会点到“去广告”的会员按钮。
3. 按钮上只有“×”：打开“诊断记录”，打开那个 App 等广告出现，回来点“复制最近一次”，把内容贴到 [Issues](../../issues) 里。**贴之前请自己看一眼**，里面有那个 App 界面上的文字。

## 隐私

- 没有申请任何权限，尤其没有联网权限，代码里也没有联网的部分。
- 检查“跳过”按钮只在手机内存里比对文字，不保存、不外传。
- 诊断记录默认关闭；开启后只保存在本机，输入框和密码框里的内容不会记录。
- 所有设置都只保存在本机。

## 开发

- 需要 JDK 17 和 Android Studio。
- 运行测试并编译：`./gradlew testDebugUnitTest assembleDebug`
- 发布新版本的步骤见 [RELEASING.md](RELEASING.md)。
- 界面只用系统自带的控件，没有第三方依赖（测试用的 JUnit 只在电脑上运行，不会打包进 App）。
